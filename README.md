# 💅 DARWN.NAILL — бот записи для nail-мастера

Telegram-бот + **Mini App** для Дарины, мастера маникюра (стаж 3 года).
Один файл [`worker.js`](worker.js) на Cloudflare Workers + база D1. Никаких серверов, ноль рублей.

## ✨ Что умеет

**Клиенту:**
- 🖼 Красивый Mini App: каталог услуг, выбор окошка по календарю, запись в 3 тапа
- 📅 «Мои записи» с отменой и кнопкой «Добавить в Google-календарь»
- 💌 Уведомления: подтверждение записи + напоминание накануне визита (cron)
- 🔥 Акции, портфолио, контакты

**Мастеру (`/admin`):**
- 🗓 **Окошки** — добавить по одному (своё время тоже можно), удалить любое или **снести ВСЕ одной кнопкой**
- 💅 **Услуги** — полный CRUD: добавить, править цену/название/время/описание, скрыть, удалить
- ✏️ **Тексты** — приветствие, «о мастере», контакты, акция, ссылки — всё правится из телефона
- 📣 **Рассылка** — текст или фото всем клиентам
- 📋 **Записи** — карточка с @username клиента, подтвердить/отклонить, написать клиенту
- 📊 Статистика и ожидаемая выручка
